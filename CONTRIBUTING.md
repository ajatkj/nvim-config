# Contributing

Thanks for taking the time to improve this Neovim configuration.

## Before opening a pull request

- Keep changes focused and compatible with Neovim 0.12 or newer.
- Put general options and keymaps in their existing central modules.
- Keep plugin specifications small and focused.
- Avoid machine-specific absolute paths; use environment variables or Neovim runtime paths.
- Run the repository checks and describe any environment-specific limitations.

## Pull requests

Explain the motivation, affected configuration areas, and manual validation performed. Screenshots or a short recording are useful for visible UI changes.
